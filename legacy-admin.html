Setup Guide

  1. In Google Forms, create a new form for each of the eight sections.
  2. Add the questions exactly as listed in the tables above.
  3. In the Responses tab, click the Sheets icon and choose "Select existing spreadsheet", then pick your VF Gift Shop Google Sheet.
  4. Do this for all eight forms. (Google Forms makes a separate "Form Responses" sheet for each one — this is normal.)
  5. Open your VF sheet → Extensions → Apps Script, paste in the contents of form-sync.gs, and Save.
  6. In Apps Script, click the clock icon (Triggers) → Add Trigger: function onFormSubmit, event "On form submit", source "From spreadsheet". Save and approve the permission prompt.
  7. Submit each form once to test — the entry should appear in the matching tab (and on the site).
  8. Copy each form's share link and paste it into the FORM_LINKS block at the bottom of admin.html.

About column names: the site reads fields like image_url, display_order, is_visible, is_active, rep_id, commission_rate, and order_amount. Name your form questions to match the headers already in your sheet — matching ignores case, spaces, and underscores, so Image URL and image_url both work. When in doubt, open the sheet and copy the exact header text.

Tip: The sync script copies every new form submission into the right tab automatically. You never need to edit or re-publish anything — just make sure the header names match.

Tip: Google Drive images only appear on the site when the file is shared as "Anyone with the link — Viewer". If a product shows the icon fallback instead of a photo, open the Drive file, click Share, and set link sharing to anyone.

Privacy: These tabs are published so the site can read them, which means anyone with the link can see every row — including sales reps' payouts and commission figures. Never put private contact numbers, addresses, or financial notes in these tabs. Keep anything sensitive in a separate, unpublished sheet.

Owner Guide

First-time setup — from zero to a live catalogue
  1. Create a Google Sheet and make 9 tabs with these exact names: Site Settings, Products, Portfolio, Testimonials, Why Us, How to Order, FAQs, Sales Reps, Payouts.
  2. Add a header row to each tab using the columns in the Column Reference above. Products has the most — only name, description, image_url, and category are required; everything else is optional.
  3. Click Share → set access to "Anyone with the link" → role Viewer.
  4. In the sheet, go to Extensions → Apps Script, paste the contents of form-sync.gs, and Save.
  5. Click the clock icon (Triggers) → Add Trigger: function onFormSubmit, source "From spreadsheet", event "On form submit". Save and approve the permission prompt once.
  6. Create one Google Form per content type (Products, Portfolio, Testimonials, Why Us, How to Order, FAQs, Sales Reps, Payouts) with questions named to match the headers.
  7. Point each form's Responses at this spreadsheet — Google adds a separate "Form Responses" sheet per form, which is normal. The script copies submissions into the real tabs automatically.
  8. Submit each form once to test. The row should appear in the matching tab; if it doesn't, check View → Logs in Apps Script for "No matching tab."
  9. Copy each form's Send link into the FORM_LINKS block at the bottom of admin.html. The "Add an FAQ" card stays inert until its faqs link is added here.
  10. Set the owner passphrase (below), redeploy, then refresh the site to confirm every section appears.

Owner passphrase: the admin page uses a client-side speed-bump, not real security. Put the SHA-256 hash of your passphrase in the ADMIN_PASS_HASH constant inside admin.html — the comment above it shows how to generate the hash. Then redeploy.

Update content day-to-day
  • Two ways to add content: the Google Forms above write to the tabs automatically, or you can edit a tab directly in Sheets. Either way, save and refresh the site — the live page picks changes up within a few minutes (data is cached for 10 minutes).
  • Products: every name must be unique — share links and product previews identify items by name. occasion takes comma-separated tags (e.g. Birthday, Wedding) and powers the occasion filter. featured = true puts the product in the top "Featured Pieces" strip, which hides while any filter is active. Set in_stock to false / 0 / no to turn the card into Sold Out with an Enquire on WhatsApp button. stock_label customizes that badge (e.g. Pre-Order Only).
  • Reps & payouts: onboard a rep with a code (rep_id) and a number like 10 for the commission_rate. Record a sale under Payouts using the rep's exact code — status is case-insensitive (paid / PAID / pending). The rep sees everything on reps.html.
  • Settings changes apply instantly to headings, hero copy, and the WhatsApp number — no redeploy needed for content.
Troubleshooting
  • Section not showing — tab name differs (spaces/caps matter), the tab has no visible rows (blank counts as visible; only FALSE / 0 / no hide), the sheet isn't shared as Viewer, or headers don't match.
  • Product photo missing — the Drive file must be shared "Anyone with the link — Viewer"; otherwise the card falls back to a placeholder icon.
  • Form submission not appearing — question names don't match the headers, or the trigger is missing. Check View → Logs in Apps Script for "No matching tab."
  • Site looks stale after an edit — data is cached for ~10 minutes; refresh again and wait a moment.
  • Payout not on a rep's dashboard — the Payout's rep_id must match the rep's code exactly (case-insensitive).
  • "Add an FAQ" card doesn't open — there's no faqs entry in FORM_LINKS yet; add one after creating the FAQ form.
  • Links / images broken — confirm each form link and image URL was pasted without spaces.
